## 🔥 **What You Can Do**

### 🌀 **Quantum Gates & Operations**
```python
# Create and manipulate qubits
alice = cq.create_qubit("Alice")
bob = cq.create_qubit("Bob")

# Apply quantum gates
alice.hadamard()        # Superposition: |0⟩ + |1⟩
alice.pauli_x()         # Quantum bit flip
alice.pauli_z()         # Phase flip
alice.cnot(bob)         # Quantum entanglement!

# Observe without destroying (consciousness advantage!)
alice.peek()            # See state without measurement
alice.measure()         # Collapse superposition
alice.show_history()    # See all operations
```

### 🔬 **Famous Quantum Algorithms**

#### 🔔 **Bell States** - Quantum Entanglement
```python
qc.bell_experiment()
# Creates spooky action at a distance between Alice and Bob!
```

#### 🔍 **Grover's Search** - Quantum Speedup  
```python
qc.grovers_search(['needle', 'hay', 'hay', 'hay'], 'needle')
# Find items √N times faster than classical computers!
```

#### 🚀 **Quantum Teleportation** - Instant State Transfer
```python
alice.hadamard()  # Prepare a quantum state
qc.quantum_teleportation('Alice')
# Teleport Alice's state to Bob instantly!
```

#### 🔢 **Shor's Algorithm** - Break Encryption
```python
qc.simple_shor_demo(15)
# Factor numbers using quantum period finding!
# Result: 15 = 3 × 5 (this is how RSA could be broken!)
```
