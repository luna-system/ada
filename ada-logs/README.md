# Ada Log Intelligence 📊

> **Biomimetic log analysis for kids and DevOps**

Understand Minecraft crashes AND production logs using research-validated importance scoring from Ada's cognitive architecture.

## Quick Start

```bash
# Install
pip install ada-logs

# Analyze Minecraft crash
ada-logs analyze crash.log --for-kids

# Compress large logs
ada-logs compress app.log --ratio 100
```
