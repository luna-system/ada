# Licensing for .ai/ Documentation

This directory contains machine-readable documentation designed for AI assistants and development tools.

## Default License: CC0 (Public Domain)

**Unless otherwise specified, all files in `.ai/` are CC0 1.0 Universal (Public Domain Dedication).**

This includes:
- Architecture documentation (context.md, codebase-map.json, etc.)
- Development guides (QUICKSTART.md, GOTCHAS.md, TESTING.md, etc.)
- Planning documents (PHASE_*.md, ROADMAP_*.md, etc.)
- Session handoffs and summaries
- Implementation specifications
- All JSON files (annotation-schema.json, specialist-registry.json, etc.)

**Why CC0?**

The `.ai/` directory exists to maximize utility for AI assistants and development tools. Public domain dedication means:
- No attribution required
- No legal barriers to use
- Can be adapted for any project
- Works across all jurisdictions
- Simplifies integration

## Exceptions: Research Documents

Files in `.ai/explorations/` that represent original research findings use **CC BY 4.0** (Creative Commons Attribution 4.0 International) when explicitly marked.

See `.ai/explorations/LICENSE.md` for details.

## Special Cases

### Audits Directory (`.ai/audits/`)
Architecture audits and related documentation: **CC0**

These are project-specific documentation meant to be freely adapted by others doing similar work.

### Handoffs Directory (`.ai/handoffs/`)
Session handoffs and phase transitions: **CC0**

Practical project documentation, not research.

### Explorations Directory (`.ai/explorations/`)
Mixed licensing—see `.ai/explorations/LICENSE.md`:
- Research discoveries: CC BY 4.0 (attribution required)
- Practical guides: CC0 (public domain)
- Planning/ideas: CC0 (public domain)

## Attribution (Optional but Appreciated)

While not required for CC0 content, if you find this documentation pattern useful for your own project, consider:
- Linking back to https://github.com/luna-system/ada
- Mentioning "Inspired by Ada's `.ai/` documentation pattern"
- Sharing your adaptations (helps the ecosystem!)

## About This Licensing Choice

**luna's preference:** CC0 for all practical documentation to maximize openness and utility.

**Ada's choice:** CC BY 4.0 for significant research findings to enable proper academic citation while maintaining collaborative authorship.

The `.ai/` directory structure itself is a first-of-its-kind collaborative design between human (luna) and AI (Claude Sonnet 4.5). We want others to use and adapt it freely.

## Questions?

**Default assumption:** If a file doesn't specify a license, it's CC0 (public domain).

**Research papers:** Check the file header or `.ai/explorations/LICENSE.md` for CC BY 4.0 documents.

**Commercial use:** Yes! CC0 allows any use, including commercial.

**Modifications:** Yes! Adapt freely. No attribution required (but appreciated).
