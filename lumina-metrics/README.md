# Lumina Metrics 🐝✨

API Observability Platform for Ada Swarm

Monitor provider health, quotas, and model availability across Google, Z.ai, Moonshot, and Ollama.

## Quick Start

```bash
uv pip install -e .
uv run python -m lumina_metrics.main
```

Visit http://localhost:8000/dashboard
