# Ada VS Code 1.1.0 Roadmap

**Status:** Planning Phase  
**Target:** Next release after 1.0.0 foundation  
**Focus:** Enhanced tool integration + better UX

---

## Priority Features

### 1. Expanded MCP Tool Support (High Priority)

**Current State:**
- ✅ `ada_introspect` working
- ✅ Intent classification for introspection
- ❌ Other tools (search_memory, add_memory, complete_code) not integrated

**Goal:** Support all MCP tools in chat interface

**Implementation:**
```typescript
// Expand classifyIntent() to detect:
- Memory search: "remember when...", "what did we discuss about..."
- Memory add: "remember this:", "save that..."
- Code completion: "complete this function:", "fill in..."
- File ops: "read file X", "write to Y"
```

**Effort:** 3-4 hours  
**Benefit:** Full MCP capability in chat

---

### 2. Tool Result Visualization (Medium Priority)

**Current State:**
- Tool results shown as plain text
- Metadata displayed as badges
- No special formatting

**Goal:** Rich visualization of tool results

**Examples:**
- Introspection: Collapsible tree view of modules
- Memory search: Timeline of retrieved memories
- File reads: Syntax-highlighted code blocks
- Command output: Terminal-style formatting

**Implementation:**
- Custom webview components
- Structured message types
- CSS styling for each tool type

**Effort:** 4-6 hours  
**Benefit:** Professional polish, easier to understand results

---

### 3. Context Awareness (Medium Priority)

**Current State:**
- Each message is independent
- No conversation history in prompts
- Brain handles memory via RAG

**Goal:** Better multi-turn conversations

**Implementation:**
- Track conversation history (last 5-10 messages)
- Include in brain prompts
- "Follow-up" detection (pronouns, "that", "it")

**Effort:** 2-3 hours  
**Benefit:** More natural conversations

---

### 4. Quick Actions Expansion (Low Priority)

**Current State:**
- 3 welcome screen buttons
- Generic prompts

**Goal:** Context-aware quick actions

**Examples:**
- When file open: "Explain this file", "Find TODOs"
- When error shown: "Debug this error"
- When diff visible: "Review these changes"

**Effort:** 3-4 hours  
**Benefit:** Faster workflows

---

## Technical Debt

### 1. Test Coverage (High Priority)

**Current State:**
- Documentation-style tests in test files
- Not actually mocked/running
- Manual testing only

**Goal:** Real test suite

**Implementation:**
- Mock MCPClient responses
- Test intent classification
- Test augmented prompt building
- Integration tests with test MCP server

**Effort:** 6-8 hours  
**Benefit:** Confidence in changes, catch regressions

---

### 2. Error Handling (Medium Priority)

**Current State:**
- Basic try/catch blocks
- Generic error messages
- No retry logic

**Goal:** Robust error handling

**Implementation:**
- Specific error types (ConnectionError, TimeoutError, etc.)
- User-friendly error messages
- Retry with exponential backoff
- Fallback modes (offline, degraded)

**Effort:** 3-4 hours  
**Benefit:** Better reliability

---

1. ✅ Expanded MCP tool support (critical functionality)

3. ✅ Tool result visualization (UX polish)
4. ⏭️ Context awareness (v1.2)
5. ⏭️ Quick actions (v1.2)
